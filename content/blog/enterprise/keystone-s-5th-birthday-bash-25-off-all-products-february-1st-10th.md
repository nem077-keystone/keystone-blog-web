## What is Keystone

![159NvFhC8Q4B_rj6TC8BdGw.webp](/images/blog/enterprise/keystones-5th-birthday-bash-25-off-all-products-february-1st-10th-97891a3ba9a6/159-nv-fh-c8-q4-b-rj6-tc-8-bd-gw-01ca5954cf.webp)

Keystone is a hardware wallet that prioritizes security of its users. One of the unique features of the device is that it is [**fully air-gapped**](/air-gapped-computers-and-phones-vs-hardware-wallets-whats-the-difference-458888cdd97). Keystone uses [**QR codes to transmit data**](/ever-wondered-what-your-hardware-wallet-inputs-and-outputs-9b33b4cedafd) to web-enabled devices, eliminating the risk of any remote attack through the absence of wired connection ports, WiFi, Bluetooth, NFC, or 5G chips.

Additionally, Keystone also boasts a [**Secure Element**](/secure-elements-the-last-line-of-defense-4669012d4edc) that stores and generates private keys using a truly random number generation method. The firmware is [**open-source**](/on-open-source-and-transparency-ba37fa1c1e8c) which allows users to verify its authenticity as well. For even greater security, there is also a fingerprint sensor option on the device to prevent password leakage in public places.

Keystone also has a built-in [**self-destruct mechanism**](/self-destruct-mechanisms-unique-defense-against-side-channel-attacks-4cfea3d4eff1) that activates upon tampering, instantly wiping the private key from the device to prevent data extraction by physical attackers.

Lastly, the standout security feature of Keystone is that it protects users from [**blind signing transactions**](/blind-signing-a-security-black-hole-for-the-ethereum-community-13f909b848b6). It [**decodes the transaction message hash of a smart contract into a human readable format**](https://www.youtube.com/watch?v=ElIM7-YPsMY&t=5s), then displays all the information (“From address”, “To address”, “Amount” etc.) clearly on the 4-inch touchscreen and prompts users to manually check them before signing off on it.
