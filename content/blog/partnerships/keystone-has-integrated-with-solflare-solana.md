Keystone has partnered with [Solflare](https://solflare.com) to allow users to have the best security and user experience when interacting with Solana blockchain. The new [M-6.0 firmware](https://keyst.one/firmware) enables users to connect their Keystone Essential or Pro hardware wallet with the Solflare Extension (v1.29 or newer) as a companion wallet.

Solflare is a fully-featured crypto wallet that is available as a web extension in your web browser or as a smartphone app, providing users a safe method to manage their SPL tokens and access to decentralized applications on the [Solana blockchain](https://solana.com). Keystone users can now safely stake their SOL using their Keystone Essential or Pro, and utilize the swap function to swap between tokens within their wallet.

Users of the Solana blockchain now have a fully air-gapped method to securely sign their transactions and utilize the 4” touchscreen to visually verify all the signing data and confirm transaction details. This addresses the [blind signing issue](https://blog.keyst.one/blind-signing-a-security-black-hole-for-the-ethereum-community-13f909b848b6) that is still plaguing dapps. Now Keystone can decode all the unsigned information into json format.

The Solflare web extension is the first Solana wallet integration for Keystone and the Solflare mobile app integration is already in the works.

Please follow this tutorial to use Keystone with Solflare -

[https://keyst.one/solflare](https://keyst.one/solflare)

## About Keystone

[Keystone](https://keyst.one/) is a 100% air-gapped QR code hardware wallet. The wallet is [designed](https://blog.keyst.one/keystone-product-design-principles-cd833bc11125) to maximize attack cost, minimize trust, prevent potential human error, avoid single-point-of-failures and boost interoperability. It was officially integrated with MetaMask ([Extension](https://twitter.com/MetaMask/status/1469351219290382341) and [Mobile](https://twitter.com/MetaMask/status/1517256930389110785)) as well as other top software wallets.
