Verify Code is a Keystone-exclusive feature for Multisig wallets. It generates a 6-character code based on the full wallet configuration including xPubs, derivation paths, and address format.Users can compare this code across Keystone devices to confirm they’re using the same Multisig wallet. Matching codes mean consistent configuration. Always verify with co-signers and back up your setup to prevent asset loss.
