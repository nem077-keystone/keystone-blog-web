Keystone has recognized the need for a more user-friendly interface that can accommodate different scenarios. In our current state, switching between different chains and software wallets can be quite inconvenient for users. However, the latest version of our firmware will address this issue by introducing a unified entry for scanning signatures on the “My Assets” page. This means that users can now sign transactions on any chain through a single UI, significantly improving the user experience.

We acknowledge that the crypto ecosystem is moving towards an era of multichain coexistence. With an increasing number of multichain wallets integrating with Keystone, our existing wallet interaction UI is no longer adequate. Upgrading it is therefore, a necessary solution to this problem. With its commitment to enhancing the user experience, Keystone wallet remains at the forefront of innovative wallet technology.

## Changelog

### 1. Streamlined Asset Management For Enhanced User Experience

![0glQEGljblzsn6iJb.webp](/images/blog/hardware-wallet/unveiling-keystones-revamped-ui-design-f4cc1cb1b748/0gl-qe-gljblzsn6i-jb-dbcd6b2418.webp)
![0opJEHKn4WEItyyB.webp](/images/blog/hardware-wallet/unveiling-keystones-revamped-ui-design-f4cc1cb1b748/0op-jeh-kn4-we-ityy-b-acd8a308a8.webp)

![The image on the left illustrates the old Keystone UI, while the image on the right shows the new and improved UI](/images/blog/hardware-wallet/unveiling-keystones-revamped-ui-design-f4cc1cb1b748/0-opjehkn4weityyb.jpg)

We made significant changes, with a focus on simplifying asset management for users. The previous version of the “My Keystone” page has been revamped into “My Assets”. The page now lists individual tabs for various digital currencies, such as BNB, LTC, SOL etc. This update makes it easier for users to manage their digital assets efficiently. We will also keep expanding the list with each subsequent update.

*Do note that there is no change in the process for generating new wallet addresses and signatures for ETH and all other EVM assets.

### 2. Optimizing Software Wallet Connection, Interaction & Signing
![0diZMLXa1sDbUVOkY.webp](/images/blog/hardware-wallet/unveiling-keystones-revamped-ui-design-f4cc1cb1b748/0di-zml-xa1s-db-uv-ok-y-86256905db.webp)
![0EDgvk3W_SbONFbTy.webp](/images/blog/hardware-wallet/unveiling-keystones-revamped-ui-design-f4cc1cb1b748/0-e-dgvk3-w-sb-on-fb-ty-5e36d16dec.webp)

The “Software Wallet” page has been updated and renamed to “Connect Software Wallet” to make it more intuitive and less confusing for beginner users. In addition to this change, the UI has been expanded to include and list each individual software wallet that is compatible with Keystone. This list will also be constantly updated with each subsequent update.

Now, when a user clicks the “Connect Software Wallet” button, they can see a list of compatible software wallets and select the one they want to connect to generate the corresponding QR code. These changes optimize user interaction when it comes to connecting to software wallets, making it more convenient and user-friendly.

![1ykrXZaFJM6dOJjHDSorZIA.webp](/images/blog/hardware-wallet/unveiling-keystones-revamped-ui-design-f4cc1cb1b748/1ykr-x-za-fjm-6d-o-jj-hd-sor-zia-b2f6a89d26.webp)

Another significant improvement that was also implemented is the compression of the “Broadcast Transaction QR Code” page to perfectly fit the Keystone 4-inch touchscreen, eliminating the need for users to scroll down to click on the “Done” button. This change significantly streamlines the transaction process, making it more efficient and effortless for users to complete their transactions.

### 3. Increased Size of NFT Profile Picture For Improved Visibility And Display

![0G0tRm8yUBx2Dao7.webp](/images/blog/hardware-wallet/unveiling-keystones-revamped-ui-design-f4cc1cb1b748/0-g0t-rm8y-u-bx2-dao7-3178b99eb6.webp)
![03twqHFVT03Ab611E.webp](/images/blog/hardware-wallet/unveiling-keystones-revamped-ui-design-f4cc1cb1b748/03twq-hfvt-03-ab611-e-283e3a2043.webp)

We take pride in being the pioneer hardware wallet that enable users to import NFTs as avatars, a feature that has gained immense popularity among Web3 users. Nonetheless, Keystone believes that the display size of the avatar on our device could be improved to enhance user experience. In this update, we have decided to optimize the size of the imported NFT avatar, which will provide Web3 users with a more distinct way to showcase their NFT avatars.

### Conclusion

Keystone’s commitment to enhancing user experience is reflected in our latest version update, which has been driven heavily by valuable user feedback. The optimizations made in this update demonstrate Keystone’s dedication to ensuring user satisfaction and a seamless user experience.
